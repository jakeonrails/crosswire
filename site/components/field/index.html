cw.field

A label + control + hint + error wrapper that wires for/id, aria-describedby, aria-errormessage and aria-invalid — composes cw.input by default, any control via field_for.

Examples

site/examples/field/basic.html.erb

<%= cw.field "Email", id: "field-basic-email", control: { type: "email", placeholder: "you@example.com" } %>

is already taken.

site/examples/field/error.html.erb

<%= cw.field "Username", id: "field-error-username",
             error: "is already taken.",
             control: { value: "admin" } %>

At least 8 characters, with one number.

site/examples/field/hint.html.erb

<%= cw.field "Password", id: "field-hint-password",
             hint: "At least 8 characters, with one number.",
             control: { type: "password" } %>

Used for shipping only.

site/examples/field/with-select.html.erb

<%# field_for + any control: the a11y wiring composes onto cw.select just as well
    as the default cw.input, via f.control_attrs (see Crosswire::UI::Field's own
    docstring for why that hash stays Symbol-keyed). %>
<%= cw.field_for id: "field-with-select-country", hint: "Used for shipping only." do |f| %>
  <label class="cw-field__label" for="field-with-select-country">Country</label>
  <%= cw.select(**f.control_attrs) do %>
    <option value="us">United States</option>
    <option value="ca">Canada</option>
    <option value="mx">Mexico</option>
  <% end %>
  <p class="cw-field__hint" id="field-with-select-country-hint">Used for shipping only.</p>
<% end %>

Props

No declared variants.

Morph contract

Morph: Safe
  A field's own wrapper/label/hint/error markup is a pure function of the
  presenter's constructor arguments, so any morph re-renders it identically.
  The control it wraps carries its own Morph verdict independently (`cw.input`
  is Safe; a `cw.select` composed in via `field_for` is Server-owned on its own
  terms — this presenter neither changes nor needs to know that).

CSS

/* crosswire/ui/field.css — cw-field, the label+control+hint+error wrapper
   (ui-tier-spec.md §5). Every color/length below is either a global token or one of
   THIS component's own `--cw-field-*` knobs, always consumed through `var(...)` —
   see tokens.css's own header for the override ladder.

   Deliberately styles ONLY the wrapper, label, hint and error — the control itself
   (cw-input, cw-select, or a caller's own markup) styles itself; this file has no
   business reaching into it. */

@layer crosswire.components {
  .cw-field {
    --cw-field-gap: var(--cw-space-1);
    --cw-field-hint-fg: var(--cw-color-fg-muted);
    --cw-field-error-fg: var(--cw-color-danger);

    display: flex;
    flex-direction: column;
    gap: var(--cw-field-gap);
  }

  .cw-field__label {
    font-size: var(--cw-text-sm);
    font-weight: var(--cw-weight-medium);
    color: var(--cw-color-fg);
  }

  .cw-field__hint {
    margin: 0;
    font-size: var(--cw-text-xs);
    color: var(--cw-field-hint-fg);
  }

  .cw-field__error {
    margin: 0;
    font-size: var(--cw-text-xs);
    font-weight: var(--cw-weight-medium);
    color: var(--cw-field-error-fg);
  }
}
